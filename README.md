ThermoFlux
Geothermal Reservoir Simulation, Visualization & Surrogate Modeling

ThermoFlux is a Python-based geothermal reservoir modeling project combining two-dimensional heat-transfer simulation, simplified Darcy flow, Gaussian Process Regression (GPR), and an interactive Streamlit dashboard.

Users can configure reservoir parameters, run numerical simulations, visualize temperature, pressure, and velocity fields, and evaluate surrogate-model predictions.

Model status: ThermoFlux is an educational research prototype. The current pressure field is prescribed and linear, and the heat-transfer solver is steady-state. Results are not validated predictions for a real geothermal reservoir.

Physical Model

The steady-state advection-diffusion equation is:

rho_cp * (v · grad(T)) = div(k * grad(T))

Darcy velocity is calculated using:

v = -(permeability / viscosity) * grad(P)

Where:

T: Temperature (°C).
P: Pressure (Pa).
v: Darcy velocity (m/s).
k: Effective thermal conductivity (W/(m·K)).
rho_cp: Volumetric heat capacity (J/(m³·K)).
permeability: Intrinsic permeability (m²).
viscosity: Dynamic viscosity (Pa·s).

The thermal equation is discretized using a two-dimensional finite-difference method with an upwind advection scheme.

Flow Model Limitations

The current implementation assumes a linear pressure distribution between inlet and outlet. It calculates Darcy velocity from this prescribed field rather than solving a full pressure equation. A complete CFD solver and FEM implementation are not currently included.

The application is designed to expose the following parameters:

Parameter	Unit
Reservoir length	m
Reservoir height	m
Grid resolution	Grid points
Injection temperature	°C
Initial reservoir temperature	°C
Thermal conductivity	W/(m·K)
Permeability	m²
Dynamic viscosity	Pa·s
Inlet pressure	Pa
Outlet pressure	Pa
Volumetric heat capacity	J/(m³·K)

The numerical solver calculates the steady-state temperature field and mean outlet temperature for the selected parameters.

Surrogate Modeling

ThermoFlux uses Gaussian Process Regression (GPR) to approximate the relationship between simulation parameters and mean outlet temperature.

Input parameters

Injection temperature (°C).
Mean Darcy speed (m/s).
Thermal conductivity (W/(m·K)).

Prediction target

Mean outlet temperature (°C).

The surrogate is trained on data generated by the numerical solver. Predictive performance should be measured using independent test data that were not used during training.

Evaluation Metrics
MAE: Mean Absolute Error (°C).
RMSE: Root Mean Squared Error (°C).
R²: Coefficient of determination.
Simulation time: Time required for numerical computation.
Inference time: Time required for surrogate prediction.

Simulation and inference times should be measured separately. Their comparison depends on grid resolution, hardware, model-training costs, and the number of predictions requested.

GPR uncertainty estimates do not automatically represent total physical uncertainty.

Interactive Visualizations

The Streamlit dashboard is intended to provide:

Temperature-field heatmaps.
Pressure-field heatmaps with pressure units.
Velocity-magnitude plots with directional arrows.
Conceptual injection and production well views.
Surrogate predicted-versus-simulated plots.
Parameter-effect and sensitivity plots.
GPR uncertainty intervals.
Computation-time and model-performance comparisons.

Any animation must be identified as conceptual unless a transient numerical solver is implemented. The current steady-state solver does not calculate reservoir evolution through time.

Validation and Limitations

ThermoFlux is a simplified numerical prototype.

The thermal model is two-dimensional and steady-state.
Pressure is prescribed rather than calculated by a full pressure solver.
Darcy flow assumes constant permeability and viscosity.
Boundary conditions influence the predicted temperature field.
Surrogate accuracy depends on training-data coverage and numerical-solver quality.
A surrogate does not improve the physical validity of its underlying simulation.
Mesh convergence, conservation checks, and analytical benchmark comparisons are needed before making quantitative engineering claims.
No validation against real geothermal field data is claimed.
FEM and transient thermal-breakthrough modeling remain future extensions unless separately implemented and verified.
